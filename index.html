Dashboard gadgets for Jira Cloud

Three gadgets that read your Jira data and show it on a dashboard. They make no write calls to Jira and send nothing outside Atlassian. The apps keep no data of their own; Jira keeps each gadget's settings with the dashboard.

Add a gadget to a dashboard

  1. Open a dashboard and choose Edit.
  2. Choose Add gadget and pick the gadget by name.
  3. Open the gadget's three-dot menu, choose Configure, fill in the settings and save.

Each person who opens the dashboard sees the data they are allowed to see in Jira. Two people can see different numbers from the same gadget.

Things that apply to all three

  • Time limit. A gadget has about 18 seconds to read Jira. When a project is too big to read in that time, or hits the issue cap listed on its page, the gadget says so above the numbers instead of showing a partial result as if it were complete.
  • Jira's hourly allowance. Jira limits how many calls an app can make per hour, and all sites that use an app share that allowance. If it is used up, the gadget says so and can show data again when the next hour starts (UTC).
  • Time zone. Day and month buckets use UTC. JQL dates are read in the viewer's Jira time zone, so figures at the edge of a window can differ by up to a day.
  • Filters. The bug and estimate gadgets take a JQL filter. Anything after ORDER BY is ignored.
  • Done without a resolution. Work moved to a Done status in a workflow that never sets Resolution is still counted. Its date is the moment it became Done.
  • Permissions. See Privacy and data for what each gadget reads and why.
