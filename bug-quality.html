Bug Aging & Reopen Rate for Jira

Shows open bugs by age and priority, how often fixed bugs come back, how long fixes take, and, if you set it up, how many new bugs escaped.

Set up

Add the gadget, open its three-dot menu, choose Configure and fill in:

  • Bug filter (JQL). Which bugs count. The default is issuetype = Bug. Use it to limit the gadget to a project, a set of projects or a component, for example project in (APP, API) AND issuetype = Bug.
  • Escaped-bug filter (JQL), optional. Which of those bugs count as escaped, for example labels = customer-found or priority in (Highest, High). Leave it empty to hide the escape rate.
  • Months. How many months of trend to show: 3, 6, 9 or 12 (default 6).

What the numbers mean

FigureDefinition
Open bugsBugs whose status is not in the Done category
Median ageMedian days since creation of the open bugs
85% are younger thanThe age that 85% of open bugs are below
Time to fixDays from creation to the moment the bug was resolved, for bugs that are resolved and not open now, by month of resolution; median and 85th percentile. The moment is the resolution date, or when the bug entered the Done category if the workflow sets no resolution
Reopen rateMoves from a Done status back to an open one in a month, divided by resolutions in that month. It can pass 100%
Most reopenedBugs with the most reopen events inside the trend window
Escape rateShare of bugs created in a month that also match the escaped-bug filter

Status categories decide what is open, and a bug moved to Done without a resolution date still counts as fixed, so custom workflows need no setup.

Limits

  • Up to 600 bugs are read: all open ones plus those resolved inside the trend window. If there are more, the gadget says "more than 600" and shows what it read.
  • Up to 1,000 escaped bugs are read. If there are more, the escape rate is a lower bound and the gadget says so.
  • Statuses that no longer belong to an active workflow cannot be classified. Transitions through them are counted and reported in a note, not guessed.
  • Month buckets use UTC.
